# RefConcept Design References

These files are user-provided / approved visual references and must guide the implementation of the RefConcept interface.

## Files

- `brand_colors.jpg` — approved brand palette and icon-line direction
- `dashboard.jpg` — desktop dashboard / budget / project management feel
- `hero_room.jpg` — homepage hero composition and room visual treatment
- `mobile_ai_marketplace.jpg` — mobile AI + marketplace + budget flow
- `mobile_ops_ar.jpg` — mobile professionals / project timeline / AI assistant / profile / AR flow
- `ui_inspiration.jpg` — website style + social identity + mini UI patterns
- `refconcept_assets_montage.png` — all design references combined

## Usage Rule

These assets are not random inspiration. They define:
- brand tone
- color palette
- luxury-minimal UI direction
- card styles
- spacing rhythm
- icon style
- mobile flow expectations
- dashboard layout expectations

Implementation should stay faithful to this direction while replacing old-brand text with **RefConcept**.
